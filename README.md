# stripkit

Strip digests and kit fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/stripkit/

## Install / run

```bash
git clone https://github.com/theworker02/stripkit.git
cd stripkit
node src/cli.js
node --test
```
